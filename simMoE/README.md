## Configuration

- 系统设定
  - 运行以上三种 MoE 模型的**推理**，目前不考虑**训练**
  - 并行计算：
    - 不使用 TP
    - 使用 DP + EP
    - 需要添加 EP 过程中的通信/计算交叠的 Feature
    - Batch Size **待定**
  - GPU：
    - 按照 4 个 H800 的硬件参数配置系统（网络带宽受限）
    - 完全不使用 NVLink，而是使用 400 Gbps 的网卡，使用 IBGDA
    - GPU 和 NIC 之间的连接使用 PCIe 5.0
